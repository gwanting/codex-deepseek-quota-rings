# DeepSeek 余额视图

中心仅显示数字：余额 ≥1 元时舍去小数，不足 1 元时保留两位小数；详情仍显示精确金额。字体、字号、居中位置及双环尺寸与 Codex 一致。外圈为当前余额相对固定基准的进度，默认人民币 20 元对应 100%；外圈颜色表示余额预警：小于 5 元红色，5–不足 10 元黄色，10–20 元蓝色，超过 20 元绿色。内圈完整度表示距下次峰谷切换的剩余时间比例，逐秒更新；切换后重新满圈，周末与节假日作为连续谷期处理。内圈颜色为峰期红色、谷期绿色。

60×60 像素，透明背景；点击任意圆环位置查看详情，再次点击圆环或点击外部收起。右键可刷新、设置外观与满圈基准、查看“关于”或退出；菜单也支持点击圆环或外部关闭。悬停可查看峰谷倒计时；详情面板的“去充值”按钮用默认浏览器打开官方充值页。

详情面板及右键菜单使用磨砂背景，支持深浅色和 0%–100% 透明度；100% 时完全去除背景材质，文字和按钮保持清晰。透明度支持按住滑块或轨道拖动，松开自动保存；外观文件位于 `%LOCALAPPDATA%\DeepSeekQuotaUsage\appearance.json`，不随源码和便携包分发。详情展开、收起带缩放动画，连续点击可反转动画。

每 60 秒只读查询 DeepSeek 官方余额，直接读取当前用户在 Win-CodexBar 中保存的 DeepSeek 密钥，兼容其 DPAPI 存储格式。密钥不另存、不输出。查余额不发起模型任务。

今日消费与 Token 通过“登录用量”接入官方开放平台账户统计：北京时间按日汇总所有 API Key、模型，Token 包含缓存命中输入、缓存未命中输入及输出，显示为亿／千万／百万。独立登录窗口需要系统 WebView2 Runtime，构建依赖由 `build-platform.ps1` 固定版本下载并校验。登录态与统计缓存仅保留在本机用户目录，详细说明见 [PLATFORM_USAGE.md](PLATFORM_USAGE.md)。

`balance-reference.example.json` 是公开的 20 元默认基准，和用户真实余额无关。运行时设置存放在 `build/balance-reference.json`，不纳入 Git。其他说明见根目录 README。
