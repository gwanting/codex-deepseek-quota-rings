# DeepSeek 余额视图

中心仅显示数字：余额 ≥1 元时舍去小数，不足 1 元时保留两位小数；详情仍显示精确金额。字体、字号、居中位置及双环尺寸与 Codex 一致。外圈为当前余额相对固定基准的进度，默认人民币 20 元对应 100%；外圈颜色表示余额预警：小于 5 元红色，5–不足 10 元黄色，10–20 元蓝色，超过 20 元绿色。内圈完整度表示距下次峰谷切换的剩余时间比例，逐秒更新；切换后重新满圈，周末与节假日作为连续谷期处理。内圈颜色为峰期红色、谷期绿色。

60×60 像素，透明背景；点击任意圆环位置查看详情，点击外部收起。右键可刷新、设置满圈基准或退出。悬停可查看峰谷倒计时；详情面板的“去充值”按钮用默认浏览器打开官方充值页。

每 60 秒只读查询 DeepSeek 官方余额，直接读取当前用户在 Win-CodexBar 中保存的 DeepSeek 密钥，兼容其 DPAPI 存储格式。密钥不另存、不输出。查余额不发起模型任务。

`balance-reference.example.json` 是公开的 20 元默认基准，和用户真实余额无关。运行时设置存放在 `build/balance-reference.json`，不纳入 Git。其他说明见根目录 README。
